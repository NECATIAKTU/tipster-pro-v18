
# TIPSTER KARTAL V1

TIPSTER PRO V18 icin bagimsiz gol analiz ve gelistirme modulu.

Amac:
- 1.5 UST yogunlugunu arastirmak
- 2.5, 3.5, 4.5, 5.5 ve 6.5 UST firsatlarini incelemek
- Model yuzdelerini analiz etmek
- Gercek sonuclarla performansi olcmek

KURALLAR:
- Mevcut V18 tahmin motoru degistirilmez.
- ASLAN MODU degistirilmez.
- Mevcut panel ve tahmin arsivi korunur.
- Yeni model bagimsiz olarak test edilir.
