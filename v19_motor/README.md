
# TIPSTER PRO V19 - ANA MOTOR

V18 tahmin motorunu geliştirmek için bağımsız test modülü.

Hedefler:
- 1.5 UST yogunlugunu analiz etmek
- 2.5, 3.5, 4.5, 5.5 ve 6.5 UST olasiliklarini hesaplamak
- Ev ve deplasman performansini ayirmak
- Gercek mac sonuclariyla modeli test etmek
- Yanlis tahminleri ve veri hatalarini incelemek

KURALLAR:
- Mevcut V18 motoru korunur.
- ASLAN MODU degistirilmez.
- Eski tahmin kayitlari silinmez.
- V19 once bagimsiz test edilir.
- Basari dogrulanmadan ana motora gecilmez.
